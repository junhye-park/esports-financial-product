# e스포츠 산업지수 기반 금융상품 설계

정형·비정형 데이터를 결합한 e스포츠 산업지수 ESI를 설계하고, 이를 기초로 ETF와 커버드콜형 금융상품 구조를 제안한 팀 프로젝트입니다.

## 프로젝트 개요

* 수행 형태: 4인 팀 프로젝트
* 관련 교과목: 핀테크 캡스톤디자인
* 대외활동: 제21회 전국 대학생 증권·파생상품 경시대회 출품
* 담당 역할: 팀 리더, 자료조사, 보고서 작성
* 주요 결과물: e스포츠 산업지수와 연계 금융상품 설계안

## 프로젝트 배경

국내에는 e스포츠 산업을 직접적으로 반영하는 금융상품이 부족하다는 점에 주목했습니다. 기존 게임·e스포츠 ETF가 주가와 매출 등 정형 데이터를 중심으로 구성된다는 점을 검토하고, 시청 지표와 SNS 언급량 등 시장의 단기적인 관심도를 함께 반영할 수 있는 산업지수를 설계했습니다.

## ESI 지수 구조

ESI는 시장 반응성을 반영하는 단기지수와 산업 안정성을 반영하는 장기지수로 구성했습니다.

### ESI Base 단기지수

| 구성 지표   | 가중치 |
| ------- | --: |
| 시청 지표   | 40% |
| 상금 규모   | 20% |
| 스폰서 수   | 20% |
| 대회 수    | 10% |
| SNS 언급량 | 10% |

### ESI Adjust 장기지수

| 구성 지표             | 가중치 |
| ----------------- | --: |
| e스포츠 관련 상장기업 주가지수 | 40% |
| 거래량지수             | 40% |
| e스포츠 ETF 수익률 변화   | 10% |
| 장기 투자자금 유입 규모     | 10% |

각 지표는 단위 차이를 줄이기 위해 Z-score 방식으로 표준화하도록 설계했습니다.

## 최종 통합지수

산업의 지속 가능성과 시장 안정성을 우선 반영하면서 팬덤과 시장의 단기적인 반응도 포함하기 위해 다음과 같이 최종지수를 구성했습니다.

```text
ESI = 0.6 × ESI Adjust + 0.4 × ESI Base
```

프로젝트 초반에는 장기 안정성과 단기 시장 반응 중 어느 요소를 우선해야 하는지를 두고 팀 내 의견이 나뉘었습니다. 팀원들의 의견을 장기 안정성, 단기 반응성, 데이터 확보 가능성, 산정 기준의 객관성으로 구분해 비교했고, 논의를 거쳐 장기지수 60%와 단기지수 40%를 최종안으로 결정했습니다.

## 제안 금융상품

### ESI 추종 ETF

ESI를 기초지수로 활용해 e스포츠 관련 기업에 분산투자하는 테마형 ETF를 제안했습니다.

### 커버드콜형 ETF

e스포츠 관련 자산을 보유하면서 콜옵션을 매도해 옵션 프리미엄을 확보하는 구조를 설계했습니다. 프리미엄이 하락 손실을 일부 완충할 수 있지만 기초자산 가격이 하락하면 손실이 발생할 수 있고, 가격이 크게 상승할 경우 수익이 제한될 수 있다는 특성도 함께 검토했습니다.

### 성과연동형 보상 구조

ETF 편입기업의 후원팀 또는 소속팀이 주요 국제대회에서 성과를 달성하면 투자자에게 추가 혜택을 제공하는 구조를 제안했습니다. 실제 상품화를 위해서는 재원, 운용규정, 투자자 간 형평성과 관련 법규에 대한 추가 검토가 필요합니다.

## 담당 역할

* 팀 일정과 역할 조율
* e스포츠 산업 및 기존 금융상품 사례 조사
* ESI 구성지표와 데이터 출처 조사
* 장기지수와 단기지수의 가중치 논의 정리
* 금융상품 구조와 위험요인 정리
* KRX 경시대회 제출 보고서 작성

## 프로젝트 한계와 개선 방향

* 실제 시계열 데이터를 적용한 백테스트가 필요합니다.
* 지수 가중치에 대한 민감도 분석과 통계적 검증이 필요합니다.
* SNS 데이터의 조작 가능성과 API 정책 변경 위험을 고려해야 합니다.
* 해외기업 편입 시 환율과 국가별 시장 차이를 반영해야 합니다.
* 실제 ETF와 커버드콜 상품화를 위해 유동성, 추적오차와 관련 법규를 검토해야 합니다.
